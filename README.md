# CCNA Master

A mobile-first, installable learning platform for the Cisco CCNA 200-301 exam, built with React, TypeScript, Vite, Tailwind CSS, and PWA support.

## Development

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run lint
npm run build
```

The Vite base path is configured for deployment at `https://glenn169.github.io/ccna-master/`.
